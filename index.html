导演工作原则 (Director Axioms)

1. 证据镜头 (Evidence) 证明功能真实发生，以真实物理运动传递底盘与动力算法信服力。
2. 记忆镜头 (Hook) 3秒内给受众植入记忆钉子，强化卖点差异化。
3. 终局收敛 (Hero Shot) 每条片尾锁定经典雕塑光，确立奇瑞新一代旗舰工业美学。
4. 克制包装 (AE / UI) HUD/动效仅辅助阐述原理解析，绝不喧宾夺主掩盖实拍质感。

现场高风险项与规避对策 (Risk Control)

风险情境 现场应急与执行预案 责任人 / 级别
泊车/充电触发偶发失败 连续彩排2-3次，地面用暗色T型胶带标记最佳轮胎起始角度；工程车辆保留手动干预切口。 车辆工程负责人 ｜ P0
车机 UI 弹出异常弹窗 提前设置车机为“演示/飞行模式”，关闭低电/蓝牙配对弹窗；全部页面以高清录屏做合成兜底备份。 车机软件对接 ｜ P1
非职业演员动作僵硬 导演指令：所有提枪、扫码动作放慢20%，以身体躯干自然借力，避免摆拍凝固感。 执行导演 ｜ P2
现场环境杂乱/反光干扰 必备CPL偏振镜消除车窗与地面眩光；主光用黑旗遮挡地库多余杂乱应急照明灯。 摄影指导 (DP) ｜ P1
LED/车机屏拍摄摩尔纹与频闪 开拍前快门角度对齐 180° (1/50s 或微调快门相位)；屏幕曝光补偿 +0.3EV 保留暗部层次。 DIT / 摄影大助 ｜ P0
